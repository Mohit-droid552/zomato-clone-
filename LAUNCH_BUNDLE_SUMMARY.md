# Launch Bundle Summary

## Project Name

Zomato Clone MERN Stack

## What is Included

This bundle contains a production-oriented starter for a Zomato-style food ordering platform with backend, frontend, docs, quickstart, and deployment guidance.

## Core Features

### Customer Experience

- Restaurant discovery homepage
- Search and filtering
- Restaurant detail page with menu tabs
- Add to cart and quantity controls
- Persistent cart state
- Checkout flow
- Order success screen
- Order history dashboard

### Authentication

- User register and login
- JWT-based auth
- Protected routes
- Saved addresses and profile endpoints

### Backend

- Express API
- MongoDB with Mongoose models
- Restaurant CRUD
- Food item CRUD
- Order creation and history
- Partner/admin starter flow
- Global error handling
- Seed data script

### Frontend

- Vite + React
- Redux Toolkit state management
- React Router v6
- Tailwind-ready structure
- Reusable UI states for loading, empty, and error conditions

## Main Files

- `README.md`
- `PROJECT_STRUCTURE.md`
- `DEPLOYMENT_CHECKLIST.md`
- `QUICKSTART.md`
- `backend/src`
- `frontend/src`

## Local Run Order

1. Start MongoDB
2. Run backend seed and server
3. Run frontend dev server
4. Open the frontend and test flows
